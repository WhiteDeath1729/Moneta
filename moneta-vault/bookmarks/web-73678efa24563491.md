Add to Chrome Add to Firefox Edit in Dokuwiki Edit in Asciidoc Edit in Markdown Class diagram A class diagram describes the static structure of a system: its classes, their attributes and methods, and the relationships between them. It's the most common UML diagram for documenting code organization and design. In PlantUML, the syntax mirrors what you'd write in a programming language, so attributes, methods, and visibility markers feel familiar. Relationships use the same arrow style as sequence diagrams. Text in, diagram out. Declare classes, fields, and relationships in a few lines. Reads like code. + , - , # for visibility, : for types, () for methods. Annotate freely. Add notes, colors, and stereotypes without leaving the text. See common commands for features available across all diagram types.
